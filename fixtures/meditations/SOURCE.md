# Fixture source — *Meditations*, Marcus Aurelius

**Text:** Project Gutenberg eBook #2680, <https://www.gutenberg.org/ebooks/2680>, plain-text
edition <https://www.gutenberg.org/cache/epub/2680/pg2680.txt> (release date June 1, 2001). The
Gutenberg header names no translator; the register ("thou hast", "Lord and Governor of the
world") and the section numbering match Meric Casaubon's 1634 translation as reprinted in the
Temple Classics edition — an inference from the text, not a statement on the file.

**Status:** the work is in the public domain in the United States. `excerpts.txt` carries a
subset of the text without the Project Gutenberg license header, and this repository does not
use the Project Gutenberg trademark to promote anything; the eBook is cited as the source of
the words, as any edition would be. Check the license terms for your own jurisdiction and use.

**What `excerpts.txt` contains** (exact line ranges of the Gutenberg file, so the extraction is
reproducible without committing the whole book):

| Block | Gutenberg lines | Sections |
|---|---|---|
| BOOK II | 914–952 | I–V |
| BOOK III | 1113–1160 | I–II |
| BOOK IV | 1406–1481 | I–III (III is the "retire into thyself" passage) |

Each block is prefixed with its book heading and the file opens with a one-line `# SOURCE:`
header. The provenance test (`tests/test_fixture_provenance.py`) asserts that header on every
text-bearing fixture file and that every highlight span in every generated input is a
whitespace-normalised substring of this file. Nothing in `fixtures/` was typed by hand from
memory of the book.

**Why this book.** Short, aphoristic, argumentative non-fiction: each numbered entry is a
self-contained claim with its own argument — a "lesson" by construction — so highlight-sized
spans arise naturally, and a synthetic reader journal that "applies" an entry the next
morning is plausible without inventing a business context.

**What is synthetic.** Everything except the words: the highlight selections, colours,
locations, page numbers, timestamps, typed notes, the "photographed" page images, the reader
journal, and the reader-context file are all generated by `gen_fixture.py` for one imaginary
reader. They exist so the pipeline runs end to end on a clean machine with no personal data.
