# Claude Code

The working brief for an agent lives in **[AGENTS.md](AGENTS.md)** at this same directory. Read
that file; this one exists only because Claude Code loads `CLAUDE.md` by name.

It is deliberately a pointer rather than a copy. Claude Code loads this file automatically, so a
duplicate would put the whole brief into context twice in the exact invocation the README
suggests — "read AGENTS.md and build me a plan".

One line worth carrying before you open it: **stop and let your reader approve the plan before you
build anything.**
